PRODUCT ROADMAP · UPDATED 2026‑06‑15

Build the triad first. Integrate everything else.

Every version is additive depth on a stable skeleton. The core logic and wiring for all surfaces ship up front; each release fleshes out one surface. The architecture never churns — flipping a flag ships a screen.

01 · WIN CONDITION
Best at the triad

Programmable periodization, integration/normalization, and the AI co-pilot with a review-gate. Everything else is integrated.

02 · WIRING CONTRACT
Scope now, build later

Data model, routes and domain seams for all tabs exist from v1.2, so the architecture never churns.

03 · ADVANCED FIRST
Hardest version first

v1.x targets the advanced hybrid athlete. Difficulty scaling and onboarding arrive at v2.0+.

04 · FREE CORE
Free core, paid edges

The programming engine and review logic are always free. Advanced surfaces are the paywall candidates.

v2.0+ · PLATFORM · LAUNCH HORIZON

When the instrument becomes a platform.

Live sync (Terra)

Activates per-session auto-progression, push, and the live recovery agent — and replaces file import as the default path.

Difficulty scaling

Onboarding sets a level that gates which tabs and features appear. Advanced sees everything; beginners see a curated subset.

Multi-model + BYO keys

Pick models from OpenRouter and spend credits as you like. The base model stays unlimited; others are credit-based.

Intra-training mode

An app-only mode for use during a session — with AI form analysis suggested for new compound lifts.

Injury management

An injury mode set in Profile that cascades across every tab, adjusting programming, volume and validators.

Training-plan importer

Drop in a coach’s plan or a PDF; normalize it into a plan-shaped CFF and confirm it through the review-gate.

Vantix goes public once v2.0 lands — difficulty scaling and live sync are what make the advanced instrument safe to hand to everyone.

v1.2 Core triad complete ● CURRENT 2026-06-15

The third pillar lands: the AI co-pilot now proposes changes as reviewable diffs that must clear the same hard-rule validators as your manual edits. With this, all three core pillars are live and the full 7-tab IA is wired end to end.

NEW AI co-pilot with review-gate — chat a change, get a code-review-style diff, run the validators, accept or reject row by row.
NEW 7-tab IA wired end to end — Dashboard and Training are deep; Nutrition, Recovery, Health and Mind render as dimmed SOON shells on real routes.
NEW Today shell — the day’s programmed session plus a fuel target, pulled from the active mesocycle.
IMPROVED Effective-volume math now folds in synergist contribution rates, not just direct sets.
IMPROVED Validator panel shows per-rule pass / fail with the reason a change was blocked.
v1.1 Import engine hardening ● SHIPPED 2026-05-20

The integration pillar grows teeth: any export maps onto the universal event spine, unknowns route to a human-confirmed resolution queue, and overlapping sources stop double-counting.

NEW Universal importer — drop any CSV, JSON or XML export and the engine maps its columns onto canonical entities.
NEW Resolution queue — unmatched exercises and foods wait for your confirmation instead of mapping silently.
IMPROVED Streaming parser handles million-row exports without ever loading the whole file into memory.
IMPROVED Coverage tracking flags a missed or partial export so gaps are visible, not assumed.
FIXED Duplicate events across overlapping sources are now deduped by content hash.
v1.0 Programming engine ● SHIPPED 2026-04-28

The first pillar: the full macro→set periodization hierarchy with volume landmarks computed continuously, the Dashboard that visualizes them, and the weekly / meso review loop.

NEW Full macro → meso → micro → session → group → exercise → set programming hierarchy.
NEW MV / MEV / MAV / MRV volume landmarks computed per muscle group, every week.
NEW Dashboard landmark range bars — weekly volume scaled against your MRV ceiling.
NEW Weekly + meso review — diff → confirm → lock, with the baseline carried into next cycle.
v0.9 Event spine foundation ● BETA 2026-04-02

The substrate everything else stands on: a single universal event spine, raw payloads kept verbatim so nothing is a black box, and the first live connectors.

NEW Universal event spine data model — one shape for hrv, set, macro, sleep and lab events.
NEW Raw payloads stored verbatim and forever, so every derived score can be re-computed.
NEW First connectors — Garmin, Whoop, Hevy and Apple Health.

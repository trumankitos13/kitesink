Identifiers

Check a code before you send it.

ISRC, ISWC, ISNI and IPI: what each one identifies, whether a code is well formed, and where to look it up.

Paste or type one identifier. The checker says what kind it is, whether it is in the right form, whether the check digit adds up where the standard has one, and gives the form to store and the form to print. A code can pass every check and still belong to another song or person, so look it up before you rely on it. Nothing you type is sent anywhere or kept.

Or try an example from the standards:

The four formats, and where each rule comes from

ISRC International Standard Recording Code

Identifies
A sound recording or music video. Each different recording has its own.
Form
12 characters: a 5-character prefix (2 letters, then 3 letters or digits), 2 digits for the year the code was assigned, and a 5-digit number. Written for people as ISRC AA-6Q7-20-00047. The word ISRC, spaces and hyphens are not part of the code, and lower case is read as capitals.
Check digit
None. ISRC has no check digit, so a checker can only test the form.
Look it up
ISRC Search (IFPI)

Sources: IFPI: ISRC Handbook, 4th edition (2021), sections 3.3 and 5 · IFPI: ISRC structure · International ISRC Agency: Bulletin 2015/01, validating an ISRC, opened 20 November 2026.

ISWC International Standard Musical Work Code

Identifies
A musical work: the song as written, not any one recording of it.
Form
The letter T, a 9-digit work number and one check digit (ISO 15707:2022). Usually written ISWC T-034.524.680-1; the hyphens and dots are only there to help reading.
Check digit
ISO 15707:2022 says the check digit is a weighted modulus 10 and sets out the formula in an annex its public preview leaves out. The checker uses the formula in the ISO committee's 1999 papers: 1 plus each work digit times its position (1 to 9), and the check digit makes the total a multiple of 10. It gives the standard's own example, so a pass reads “consistent with the published formula”.
Look it up
ISWC-Network (CISAC)

Sources: ISO 15707:2022, clause 4 (preview) · ISWC International Agency: the ISWC · ISO/TC 46/SC 9 N 268 (1999): the check digit formula, opened 20 November 2026.

ISNI International Standard Name Identifier

Identifies
The public identity of a person or organisation, such as a performer, a writer or a label. A pseudonym can have its own.
Form
16 characters: 15 digits and a check character, which is a digit or X. Written ISNI 0000 0001 2124 1960; the word ISNI and the spaces are not part of it.
Check digit
The check character comes from the first 15 digits by the ISO/IEC 7064 MOD 11-2 method (ISO 27729, Annex A). X stands for 10.
Look it up
ISNI search

Sources: ISO 27729:2024, clause 4 and Annex A (preview) · ISNI: FAQs · IANA: ISNI namespace registration, opened 20 November 2026.

IPI Interested Party Information

Identifies
A writer or publisher in the IPI system the CISAC societies share. Each name has an IPI name number; the IPI base number ties all of one party's names together.
Form
Name number: 11 digits. An older 9-digit number is written with two leading zeros. Base number: usually written I-NNNNNNNNN-C, the letter I, nine digits and a final digit.
Check digit
No check-digit rule is published for either, so the checker tests the form only. A number in the right form may still be wrong.
Look it up
Ask your PRO or society for the IPI numbers they hold for you.

Sources: SUISA: What is the IPI number? (17 April 2025) · Harry Fox Agency: What is an IPI number? · CISAC: IPI · Wikipedia: Interested Parties Information (the base number pattern; a secondary source), opened 20 November 2026.

ISRCAn ISRC is 12 characters: a prefix, a year and a five-digit numberTwo letters and three letters or digits make the prefix, two digits give the year, and five digits finish it. IFPI describes no check digit.BeginnerSourced

The prefix belongs to the registrant and is allocated by an ISRC agency. The year element takes the final two digits of the assignment year. The five-digit designation code is picked by the registrant from its range and must not repeat within a year. On paper the code takes the letters ISRC in front and hyphens at three points, which are not part of the code. IFPI's validity test is only whether the string fits this layout.

  • Store the 12 characters with no spaces or hyphens.
  • Check the format at /music/tools#identifiers.
